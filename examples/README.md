# Examples

This folder contains small, self-contained behavior demos that exercise different parts of the registry and its helper patterns.

## Example index

- [Custom Commands](custom-commands/) — command-style behavior for invoking methods or custom commands on another element.
- [Intl Data](intl-data/) — locale-aware number formatting for native `<data>` elements.
- [Intl Time](intl-time/) — locale-aware date, time, duration, and skeleton formatting for native `<time>` elements.
- [Intl Message](intl-message/) — localized text and attribute messages, with inline script and link-based loaders.
- [Intl Behaviors](intl-behaviors/) — bundled intl example importing the language, data, message, and time behaviors together.

## Notes

Each subfolder includes an `index.html` harness and a matching JavaScript module so the examples can be served directly in a browser.
